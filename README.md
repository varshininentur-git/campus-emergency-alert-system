# Emergency Alert System 🚨
A modern and interactive Emergency Alert System website built using HTML, CSS, and JavaScript.
This project allows users to:Select emergency severity
                             Choose campus location
                             Send emergency alerts
                             View alert confirmation

The website is designed with a modern glassmorphism UI and responsive layout for a better user experience.


# 🌟 Features
✅ Modern dark-themed UI
✅ Glassmorphism design
✅ Responsive layout
✅ Interactive alert system
✅ Location selection page
✅ Alert confirmation page
✅ Smooth button hover animations
✅ User-friendly interface

# 🚀 How to Run the Project
## VS Code Live Server

1. Open project folder in VS Code
2. Install Live Server extension
3. Right-click `index.html`
4. Click:Open with Live Server
